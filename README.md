# EURO VALUE AI

Prototipo inicial de una aplicación web progresiva (PWA) para análisis personal de acciones europeas.

## Contenido
- `index.html`: interfaz inicial y módulos de demostración.
- `manifest.webmanifest`: configuración de la PWA.
- `sw.js`: service worker básico para caché offline.
- `README.md`: estas instrucciones.

## Importante
Esta versión es únicamente una estructura inicial:
- No consulta cotizaciones ni estados financieros reales.
- El cálculo DCF es ilustrativo y simplificado.
- La cartera se guarda en `localStorage` del navegador. No está cifrada ni sincronizada y puede perderse al borrar los datos del navegador.
- No introduzcas datos privados o sensibles en el repositorio público de GitHub.

## Publicación
Activa GitHub Pages desde **Settings → Pages** y selecciona la rama `main` y la carpeta `/ (root)`.
